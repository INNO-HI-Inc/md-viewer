MD Pretty Viewer

VS Code에서 마크다운을
깔끔하게 읽고 쓰기

.md 파일을 열면 바로 렌더링된 프리뷰가 보입니다.
편집도 되고, 테마도 바꿀 수 있고, 아웃라인도 나옵니다.
무료이고 오픈소스입니다.

Download (.vsix) GitHub

뭘 할 수 있나요

세 가지 모드

상단 탭에서 Preview, Edit, Split을 전환합니다. Preview에서 더블클릭하면 바로 편집 모드로 넘어갑니다.

서식 도구

Edit 모드에서 툴바가 나타납니다. 헤딩, 볼드, 이탤릭, 코드, 링크, 리스트, 인용을 버튼으로 넣을 수 있습니다. 텍스트를 선택하고 누르면 선택 영역에만 적용됩니다.

아웃라인

오른쪽 상단의 목록 아이콘을 누르면 H1~H4 헤딩 구조가 사이드바에 표시됩니다. 항목을 클릭하면 해당 위치로 이동합니다.

코드 하이라이팅

highlight.js 기반으로 코드 블록을 자동 하이라이팅합니다. 선택한 테마 색상에 맞춰 코드 색상도 함께 바뀝니다.

기타

  • 폰트 크기 12px~24px 조절, 설정 자동 저장
  • 상대 경로 이미지 렌더링
  • GFM (테이블, 체크박스, 취소선) 지원
  • Split 모드에서 에디터/프리뷰 스크롤 동기화

테마

상단바의 색상 점을 클릭하면 테마가 바뀝니다. 7가지 있습니다.

설치

Releases에서 .vsix 파일을 받은 뒤:

code --install-extension md-pretty-viewer-0.2.0.vsix

또는 VS Code에서 Extensions > ... > Install from VSIX 선택.

설치 후 아무 .md 파일을 열면 자동으로 적용됩니다.
