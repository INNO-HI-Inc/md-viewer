Features

필요한 건 다 있습니다

▶

세 가지 모드

Preview, Edit, Split. 더블클릭으로 바로 편집. Cmd+E로 토글.

✎

서식 도구

헤딩, 볼드, 이탤릭, 코드, 링크, 리스트. 선택 후 버튼 클릭이면 끝.

☰

아웃라인

H1~H4 구조를 사이드바에 표시. 클릭하면 해당 위치로 이동.

</>

코드 하이라이팅

highlight.js 기반. 테마 색상에 맞춰 코드 색도 자동 변경.

Aa

폰트 크기

12px ~ 24px. 상단바에서 바로 조절. 설정 자동 저장.

✓

GFM 지원

테이블, 체크박스, 취소선. GitHub Flavored Markdown 완벽 호환.

Install

30초면 설치 끝

VS Code Marketplace에서 md pretty viewer 검색, 또는:

code --install-extension innohi.md-pretty-viewer

또는 VS Code → Extensions → ... → Install from VSIX
