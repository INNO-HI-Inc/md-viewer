Features

👁

실시간 프리뷰

마크다운을 작성하면 즉시 렌더링된 결과를 확인할 수 있습니다. Preview, Edit, Split 세 가지 모드를 자유롭게 전환하세요.

🎨

7가지 컬러 테마

Blue, Green, Rose, Purple, Amber, Neutral, Mono. VS Code의 라이트/다크 모드에 맞춰 자동 최적화됩니다.

📑

아웃라인 사이드바

문서의 헤딩 구조를 한눈에 파악하고, 클릭 한번으로 원하는 섹션으로 이동합니다.

🛠

서식 도구 모음

볼드, 이탤릭, 코드, 링크, 리스트, 인용 등 마크다운 서식을 버튼 하나로 적용합니다.

🔤

폰트 크기 조절

12px부터 24px까지, 상단바에서 바로 조절할 수 있습니다. 설정은 자동 저장됩니다.

💻

코드 하이라이팅

highlight.js 기반으로 JavaScript, Python, CSS 등 다양한 언어의 코드 블록을 자동으로 하이라이팅합니다.

Install

1

VSIX 다운로드

GitHub Releases에서 최신 VSIX 파일을 다운로드합니다.

2

VS Code에서 설치

Extensions 패널 → ... 메뉴 → Install from VSIX...

또는 터미널에서:

code --install-extension md-pretty-viewer-0.2.0.vsix
3

.md 파일 열기

아무 마크다운 파일을 열면 자동으로 MD Pretty Viewer가 적용됩니다.
