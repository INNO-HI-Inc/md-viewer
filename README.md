## Features

- **세 가지 모드** — Preview / Edit / Split. 더블클릭으로 바로 편집
- **7가지 컬러 테마** — Blue, Green, Rose, Purple, Amber, Neutral, Mono
- **서식 도구** — 헤딩, 볼드, 이탤릭, 코드, 링크, 리스트, 인용
- **아웃라인 사이드바** — H1~H4 구조 표시, 클릭으로 이동
- **코드 하이라이팅** — highlight.js 기반 자동 하이라이팅
- **폰트 크기 조절** — 12px ~ 24px
- **GFM 지원** — 테이블, 체크박스, 취소선

## Install

[Releases](https://github.com/INNO-HI-Inc/md-viewer/releases/latest)에서 `.vsix` 다운로드 후:

```bash
code --install-extension md-pretty-viewer-0.2.0.vsix
```

또는 VS Code → Extensions → `...` → Install from VSIX

## Shortcuts

| 단축키 | 기능 |
|--------|------|
| `Cmd+E` | Preview / Edit 전환 |
| `Cmd+B` | 볼드 |
| `Cmd+I` | 이탤릭 |
| `Cmd+Shift+C` | 코드 |
| `Tab` | 들여쓰기 |
